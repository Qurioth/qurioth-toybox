# タイトル

このシナリオは"クトゥルフ神話TRPG ルールブック 7版"に対応したシナリオで、探索者 i ～ j 人向けにデザインされている。  
プレイ時間は探索者の作成時間を含まずに n 時間程度だろう。  
舞台は現代の日本。探索者たちが事件に関わることになるきっかけを記載する。
