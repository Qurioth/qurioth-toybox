# シナリオデータ

自作シナリオの本文と、それを `/trpg/scenario` へ出すためのデータを置くディレクトリ。
本文 Markdown の記述規約はこのファイルにまとめてある。既存シナリオ 12 本で優勢だった記法を
正としており、新規作成・修正時はこの規約に従う。

```
src/data/scenario/
  README.md         # この文書(記述規約)
  template.md       # 新規シナリオの雛形。コピーして書き始める
  scenario-list.ts  # 一覧・詳細に出すシナリオの登録
  markdown/         # シナリオ本文
```

規約が対象とするのは **クトゥルフ神話TRPG 7版** のシナリオ。2 章のセクション構成がこのシステムを
前提にしているため、他システムのシナリオ（`queen-of-the-sea` は「駆け出しアイドルRPG
ビギニングアイドル」）は章立てをそのシステムの進行に合わせ、4 章の表記規約だけを適用する。
決定の経緯は [ADR-0014](../../../docs/adr/0014-establish-scenario-markdown-conventions.md) を参照。

## 1. ファイルと登録

| 対象         | 規約                                                                    |
| ------------ | ----------------------------------------------------------------------- |
| 本文         | `src/data/scenario/markdown/<slug>.md`                                  |
| `<slug>`     | 原題または邦題を英語化した kebab-case（例: `bubble-on-wet-hands`）      |
| 画像         | `public/images/<slug>/<name>.png` を `/images/<slug>/<name>.png` で参照 |
| 一覧への登録 | `src/data/scenario/scenario-list.ts` に PascalCase キーでエントリを追加 |

`scenario-list.ts` のエントリは以下を全て埋める。`summary` は一覧カードに出るため 1 文で簡潔に書く。

```ts
BubbleOnWetHands: {
  system: "クトゥルフ神話TRPG 7版",
  title: "濡れた手の泡沫",
  titleKana: "ぬれたてのほうまつ",
  players: { min: 3, max: 5 },
  playTimeHours: { min: 5, max: 6 },
  summary: "現代日本。知人の沖嶋 深月の依頼で一人の男性を捜し、海沿いの町へ赴く。",
  markdown: readScenarioMarkdown("bubble-on-wet-hands.md"),
},
```

## 2. セクション構成

上から以下の順で並べる。任意のセクションは不要なら省略する。

| #  | セクション          | 要否 | 内容                                                     |
| -- | ------------------- | ---- | -------------------------------------------------------- |
| 1  | `_サブタイトル_`    | 任意 | H1 の前に斜体 1 行。原題・訳題・副題を置く               |
| 2  | `# タイトル`        | 必須 | 文書中で H1 は 1 つだけ                                  |
| 3  | 概要リード          | 必須 | 対応ルールブック・人数・プレイ時間・舞台・前提（後述）   |
| 4  | `## GM 向け情報`    | 必須 | 事件の真相。プレイヤーに伏せる情報をここに集約する       |
| 5  | `## 特殊 HO`        | 任意 | 事前に決めてもらう設定・ハンドアウト                     |
| 6  | `## 推奨技能`       | 任意 | 箇条書き。特定技能が前提になる場合のみ                   |
| 7  | `## 主な NPC`       | 必須 | NPC を `###` で列挙（後述）                              |
| 8  | `## シナリオの導入` | 必須 | 探索者が事件に関わるまで                                 |
| 9  | `## <場面名>`       | 必須 | 場所・場面ごとに `##`、その中の調査対象を `###` で分ける |
| 10 | `## クライマックス` | 必須 | 対決・儀式阻止など                                       |
| 11 | `## シナリオ終了`   | 必須 | `### ED1 【名称】` … と `### その他報酬 (任意)`          |

概要リードは次の 3 行を基本とし、必要なら補足行を足す。各行の末尾は半角スペース 2 つ。

```
このシナリオは"クトゥルフ神話TRPG ルールブック 7版"に対応したシナリオで、探索者 3 ～ 5 人向けにデザインされている。  
プレイ時間は探索者の作成時間を含まずに 6 時間程度だろう。  
舞台は現代の日本。探索者たちは共通の知人である **沖嶋 深月** の依頼で一人の男性を捜し、海沿いの町へ赴くこととなる。
```

## 3. 見出しレベル

| レベル  | 用途                                                           |
| ------- | -------------------------------------------------------------- |
| `#`     | シナリオタイトル。1 ファイルに 1 つ                            |
| `##`    | 章。固定セクション名、または場所・場面名                       |
| `###`   | 節。NPC 1 人、調査対象、神話生物 1 体、エンディング 1 つ       |
| `####`  | `ステータス` `技能` `セリフ例` `正気度喪失` `装甲` `呪文` など |
| `#####` | それ以上の細分（攻撃手段、日付ごとの日記など）。多用しない     |

## 4. 表記規約

| 対象               | 書式                                       | 例                                     |
| ------------------ | ------------------------------------------ | -------------------------------------- |
| 改行               | 行末に半角スペース 2 つ                    | 行末に空白を置いたまま改行する         |
| 段落               | 空行 1 行で区切る                          |                                        |
| 技能・能力値判定   | `**〈技能名〉**`                           | `**〈目星〉**` `**〈CON〉**`           |
| 判定難易度         | 「のハード」「のイクストリーム」を後置     | `**〈STR〉** のハード`                 |
| 呪文               | `《呪文名》`                               | `《カーの分配》`                       |
| 魔的な物品・書名   | `『名前』`                                 | `『食屍鬼写本』` `『蒼白の仮面』`      |
| 正気度喪失         | `**正気度喪失：成功 ／ 失敗**`             | `**正気度喪失：0 ／ 1D6**`             |
| 正気度回復         | `正気度回復: 1D6`                          | 失う場合と違い半角コロン、太字にしない |
| NPC のセリフ       | 引用（`>`）。1 行ごとに末尾スペース 2 つ   |                                        |
| 作中テキスト       | フェンス付きコードブロック（言語指定なし） | 日記・手紙・掲示・詠唱文               |
| 一覧・条件列挙     | GFM のリスト／テーブル                     |                                        |
| NPC 立ち絵         | `![名前](/images/<slug>/<name>.png)`       | 見出し直後に単独行で置く               |
| ルールブックの出典 | `**_書名 ページ 項目名_**`                 | `**_基本ルールブック P319 黄色の印_**` |

- 本文中の NPC 呼称は原則ファーストネーム。NPC 名・神話生物名は太字にしない。
- 太字は GM がその場で処理すべきもの（判定・正気度喪失・呪文）の合図として使う。
  名詞を目立たせる用途に広げると、見落としてはいけない判定の指示が埋もれる。
- 数値と単位・記号の間には半角スペースを入れる（`3 ～ 5 人`、`0 ／ 1D6`）。
- コロンは半角 `: ` を使う。ただし `正気度喪失：` のみ全角コロンで統一する。
- 魔導書とアーティファクトは `『』` で囲む。魔力を帯びた物品はどちらも同じ扱いとし、
  唱えるものを指す `《呪文名》` とは区別する。初出だけでなく本文中のすべての言及を囲み、
  見出しに使うときも同じ（`『グハーン断章』を読み進めた`、`#### 『グハーン断章』`）。
- 見出しに括弧を付けるときは半角括弧を使い、直前に半角スペースを 1 つ置く。読み仮名でも
  それ以外の補足でも同じ（`### 沖嶋 深月 (オキシマ ミツキ)`、`## 潮上町 (シオガミチョウ)`、
  `## 潮上灯台跡 (夜間)`、`### 棚 (テレビ台)`）。用途で使い分けない。

### セリフ例

```
#### セリフ例

> 「え、お前ら Misago 知らねえの？ まじかよ、モグリか？」  
> 「とりあえず、聞きなって、やべぇから」  
> 「すげぇんだって！！」
```

### 魔導書

```
### 『魔導書名』

- 記載されている言語：日本語
- 著者：著者名
- **正気度喪失**：2D8
- **〈クトゥルフ神話〉**：+4%／+9%
- 神話レーティング：39
- 研究期間：46 週間
- 呪文：《呪文名》、《呪文名》
```

既刊の数値をそのまま使う場合は各項目に出典を書く（`**_基本ルールブック_** 準拠`、
`**_マレウス・モンストロルム Vol.2 P232_** 参照`）。出典は斜体と太字を重ねた `**_…_**` で書き、
書名を `『』` で囲まない。地の文でルールブックに言及するだけの場合は装飾しない。

## 5. ステータスと技能

### NPC

能力値は `STR CON POW DEX APP SIZ INT EDU` の順。1 行目に能力値、2 行目に副次ステータスを置き、1 行目末尾は半角スペース 2 つ。

```
### 田中 太郎 (タナカ タロウ)

![田中 太郎](/images/<slug>/taro.png)
性別。年齢。職業。  
外見・性格・来歴など。探索者との関係もここに書く。

#### ステータス

STR: 55 CON: 75 POW: 45 DEX: 60 APP: 60 SIZ: 60 INT: 85 EDU: 53  
耐久力: 13 マジック・ポイント: 9 正気度: 42 幸運: 35 ダメージ・ボーナス: +0 ビルド: 0 移動率: 8

#### 技能

運転（自動車）: 50% 芸術／製作（写真術）: 65% サバイバル（海）: 40%  
信用: 15% 水泳: 60% 説得: 35% 操縦（船舶）: 52% 図書館: 50%  
ナビゲート: 30% 母国語（日本語）: 65% 歴史: 15% ダイビング: 60%
```

- 技能は五十音順に並べ、1 行が長くなりすぎないところで改行する。
- 戦闘を行わない NPC は `#### 技能` を省略してよい。
- 副次ステータスの項目名は `耐久力` / `マジック・ポイント` / `ダメージ・ボーナス` と略さずに書く
  （`HP` / `MP` / `DB` は使わない）。ダメージ算出式の中の `DB` はそのままでよい。
- 値を決めていない項目（`正気度`、`幸運`、`ビルド` など）は省略してよい。

### 神話生物・怪物

登場する場面（多くは `## クライマックス`）の下に `###` で置く。能力値の並びは NPC と同じ
`STR CON POW DEX APP SIZ INT EDU` の順とし、持たない能力値は飛ばす。

```
### 神話生物名

姿・恐怖描写。**正気度喪失：1 ／ 1D8**

#### ステータス

STR: 60 CON: 50 POW: 50 DEX: 70 SIZ: 80  
耐久力: 13 マジック・ポイント: 11 ダメージ・ボーナス: +1D4 ビルド: 1 移動: 8 装甲: 1  
攻撃回数: 1

#### 技能

近接戦闘: 100% ダメージ 2D6+DB  
回避: 40%
```

攻撃手段が複数ある場合は `#### 行動パターン` の下に `##### 攻撃名` を並べ、`対象` `成功率` `ダメージ` を書く。

## 6. シナリオ終了

`ED1` から連番。名称は `【】` で囲む。各 ED は「到達条件」「その後どうなるか」「正気度回復」の順。

```
## シナリオ終了

### ED1 【エンディング名】

到達条件。  
その後の顛末。

正気度回復: 1D10

### ED2 【エンディング名】

到達条件。  
正気度回復: なし

### その他報酬 (任意)

探索者たちの正気度減少量と相談して与える。

#### 全員生還

正気度回復: 1D4
```

## 7. レンダリング上の制約

表示は `src/app/trpg/scenario/[id]/page.tsx` の `react-markdown` + `remark-gfm` で行う。

- 生 HTML は使えない（`rehype-raw` を入れていない）。装飾は Markdown の範囲で行う。
- `breaks` を有効にしていないため、行内改行には行末の半角スペース 2 つが必須。
- 画像は本文に右寄せで回り込む（`float-right`、`size-40` / `md:size-60`）。正方形に近い立ち絵を用意する。
- `scenario-list.ts` の `system` に「クトゥルフ神話TRPG」を含む場合、二次創作の著作権表記が末尾へ自動で付く。本文に書いてはいけない。
- テーブルは GFM 記法。Biome は Markdown を整形しないため、桁は手で揃える。

## 8. 雛形

[template.md](template.md) をコピーして書き始める。

```bash
cp src/data/scenario/template.md src/data/scenario/markdown/<slug>.md
```

雛形には節の順序と各ブロックの書式が入っている。任意の節と、書き方を案内する HTML コメントは
書き終えた時点ですべて削除する(コメントは表示されないが、本文に残さない)。
書いたら `scenario-list.ts` への登録を忘れないこと。
