# Feature Specification: TRPGツール一覧

**Feature Branch**: `002-trpg`

**対象画面**: `/trpg` (`src/app/trpg/page.tsx`)

**Created**: 2026-08-23

**Status**: Draft

**Input**: User description: "TRPG向けコンテンツの入口となる一覧画面。セッションで使うツールと、公開しているシナリオ・リプレイを分けて提示し、それぞれの入口へ案内する。既存実装の現行仕様を spec として書き起こしたもの。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 使いたいツールを選ぶ (Priority: P1)

セッションの準備や記録をしたい訪問者として、この画面に並ぶツールの中から自分の目的に合う
ものを選びたい。ツールごとに対応するTRPGシステムが違うため、開く前に見分けたい。

**Why this priority**: この画面の主目的。ツールに辿り着けなければサイトの中心的な価値が
届かない。

**Independent Test**: `/trpg` を開き、各ツールの名称・用途の説明・対応システムが読み取れ、
選ぶと該当ツールへ遷移することで確認できる。

**Acceptance Scenarios**:

1. **Given** `/trpg` を表示している状態、**When** ツールの区分を見る、**Then** ダイスログの
   集計ツール、キャラクターシートのチャート表示ツール、つながり管理表の3つが、それぞれ
   名称・説明・対応システムとともに並んでいる。
2. **Given** `/trpg` を表示している状態、**When** いずれかのツールのカードを選ぶ、**Then**
   そのツールの画面へ遷移する。
3. **Given** 対応システムが限られるツール、**When** カードを見る、**Then** どのTRPGシステム
   向けかが明示されている(例: クトゥルフ神話TRPG、ふしぎもののけRPG ゆうやけこやけ、
   システムを問わないもの)。

---

### User Story 2 - 公開している読み物・動画へ行く (Priority: P2)

訪問者として、オーナーが公開しているシナリオやリプレイ、セッションの記録を見に行きたい。
ツールとは目的が違うため、混ざらずに並んでいてほしい。

**Why this priority**: ツールへの導線が主目的だが、公開物への導線も同じ画面が担っている。
ツールより後に成立するため P2。

**Independent Test**: 読み物・動画の区分からシナリオ一覧とリプレイ一覧へそれぞれ遷移できる
ことで確認できる。

**Acceptance Scenarios**:

1. **Given** `/trpg` を表示している状態、**When** 読み物・動画の区分を見る、**Then** シナリオ・
   リプレイ・セッションの記録が、内容の説明とともにツールとは別の区分で並んでいる。
2. **Given** 読み物・動画の区分、**When** シナリオを選ぶ、**Then** シナリオ一覧画面へ遷移する。
3. **Given** 読み物・動画の区分、**When** 外部サイトで公開している項目(セッションの記録)を
   見る、**Then** 遷移先が外部サイトであることが分かり、選ぶと別タブで開く。

---

### Edge Cases

- 画面幅が狭い環境では、カードが1列に並び替わり、横スクロールを発生させない。
- ツールが増えても区分は変わらず、同じ形式のカードとして追加される。
- カードの説明文の長さがまちまちでも、区分内のカードの高さが揃い、対象の表記はカード下部に
  揃う。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 本画面は、TRPG向けコンテンツを「セッションで使うツール」と「公開しているシナリオ・
  リプレイ」の2区分に分けて提示しなければならない。
- **FR-002**: 各区分には、その区分が何を集めたものかを説明する一文を添えなければならない。
- **FR-003**: 各項目はカード形式で表示し、名称・用途の説明・対象(対応システムまたは種別)を
  含めなければならない。
- **FR-004**: 訪問者は、カードのどこを選んでも該当画面へ遷移できなければならない。
- **FR-005**: 各カードは、選択できることが分かる状態変化(カーソルを重ねたとき・キーボードで
  選択したとき)を持たなければならない。
- **FR-006**: 新しいツールやコンテンツを追加したときは、本画面のいずれかの区分から辿れる
  ようにしなければならない([constitution.md](../../.specify/memory/constitution.md) 原則2)。
- **FR-007**: 遷移先が外部サイトのカードは、対象の表記とアイコンでそれと分かるようにし、
  別タブで開かなければならない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: トップページから任意のツールまで2操作以内で到達できる。
- **SC-002**: 訪問者が、各ツールを開く前に、それが自分の遊ぶTRPGシステムで使えるかどうかを
  判断できる。
- **SC-003**: 幅375px の端末で、横スクロールを発生させずにすべてのカードを閲覧できる。

## Assumptions

- サイト共通のヘッダー・フッター・配色切替の仕様は [001-home](../001-home/spec.md) で扱い、
  本specでは繰り返さない([ADR-0013](../../docs/adr/0013-spec-per-screen.md))。
- 本画面は静的な案内のみを担い、検索・並べ替え・絞り込みは持たない。項目数が一覧性を損なう
  規模になるまでは追加しない(原則1)。
- サイト内に置かないコンテンツ(外部サービスで公開しているもの)も、該当する区分のカードとして
  同じ形式で並べる。
