# Contract: `pnpm photo:sync`

**Feature**: [../spec.md](../spec.md) | **Data**: [../data-model.md](../data-model.md) |
**ADR**: [ADR-0017](../../../docs/adr/0017-store-photos-in-r2.md)

オーナーが手元の PC で実行する取り込みのコマンド。

## 呼び出し方

```
pnpm photo:sync <slug> [--dry-run] [--prune]
pnpm photo:sync --all [--dry-run] [--prune]
```

- `<slug>`: `src/data/photograph/albums/<slug>.txt` を処理する。
- `--all`: `src/data/photograph/albums/` にあるすべての txt を処理する。
- `--dry-run`: 何もアップロード・書き込みしない(リストの相対パスへの書き換えもしない)。
- `--prune`: 処理のあと、どのアルバムデータからも参照されていない R2 の画像を消す。
- 環境変数は `.env.local` から読む(`node --env-file-if-exists=.env.local`)。

## 処理の順番

1. **読む**: リストを読み、書式を確かめる(data-model.md 1章)。
2. **確かめる**: ファイルの有無、NEF の読み替え、重複を確かめる。キーを計算する。
3. **似た写真を探す**: 撮影時刻が30秒以内で、8×8 の白黒の相関が高い組をグループにする(research R9)。
4. **報告する**: 下の「表示する内容」を出す。エラーが1件でもあれば、ここで終了する(終了コード 1)。
   `--dry-run` もここで終了する(終了コード 0)。
5. **リストを直す**: 絶対パスの行を相対パスに書き換える。書き換えた行数を表示する。
6. **作って上げる**: アルバムデータにまだないキーの写真だけ、2つの幅の WebP を作ってアップロードする。
7. **書き出す**: アルバムデータ(json)と `index.ts` を書き出し、Biome で整形する。
8. **(`--prune` のとき)消す**: R2 のキーの一覧を取り、どのアルバムデータにもないものを消す。
   消した件数を表示する。

アップロードの途中で失敗したら、そこで止める。json は書き出さない(公開中の内容は前回のまま)。
再実行すれば続きから上がる(上がっていたものは上書きになるだけ)。

## 表示する内容

```
アルバム: 2025-04-nemophila(ネモフィラ / 2025-04-05)
  写真: 51枚(新規 12枚・既存 39枚)
  表紙: DSC_0008.JPG
  外した写真: 2枚(R2 に残っています。消すには --prune)
  圧縮後の見込み: 約 9.8MB(新規分 約 2.3MB)

似ている写真:
  [1] DSC_0012.JPG, DSC_0013.JPG, DSC_0014.JPG
  [2] DSC_0040.JPG, DSC_0041.JPG

注意:
  2行目: NEF の代わりに DSC_0005.JPG を使います
  9行目: 7行目と同じ写真のため無視します

エラー:
  15行目: ファイルが見つかりません(2025年\2025-04-05 ネモフィラ\DSC_0099.JPG)
```

- 似ている写真は知らせるだけで、処理は止めない。
- 「圧縮後の見込み」は、`--dry-run` では実際に圧縮して測る(アップロードはしない)。

## エラーにするもの(本番の実行をしない)

| 状況 | 表示 |
| -- | -- |
| リストのファイルがない | 「`<slug>.txt` が見つかりません」 |
| slug の形が不正 | 「アルバム名は英小文字・数字・- だけにしてください」 |
| `# title:` / `# date:` がない・不正 | 「タイトル(または撮影日)を書いてください」 |
| ファイルがない | 「n行目: ファイルが見つかりません(パス)」 |
| `PHOTO_SOURCE_ROOT` の外の絶対パス | 「n行目: PHOTO_SOURCE_ROOT の外のファイルです」 |
| 対応していない拡張子 | 「n行目: JPG だけ対応しています」 |
| NEF で、同じ名前の JPG がない | 「n行目: NX Studio で JPG に書き出してください」 |
| 写真が0枚 | 「写真が1枚もありません」 |
| `# cover:` の写真がリストにない | 「表紙(# cover:)に指定した写真がリストにありません」 |
| `# cover:` のファイル名がリストの複数の写真に当たる | 「表紙(# cover:)に当たる写真が複数あります。フォルダから書いてください」 |
| 環境変数が足りない | 「.env.local に <名前> を書いてください」(`--dry-run` では `PHOTO_SOURCE_ROOT` だけ求める) |

## 元の写真に対して

- 読むだけで、移動・変更・削除はしない。
- 圧縮した画像はメモリ上で作り、ディスクには書かない。
