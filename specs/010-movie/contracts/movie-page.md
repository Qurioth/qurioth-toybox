# Contract: 動画一覧の画面

**Feature**: [../spec.md](../spec.md) | **Data**: [../data-model.md](../data-model.md)

画面が利用者に対して約束する振る舞い。結合テスト(`MovieList.test.tsx`、`src/app/other/page.test.tsx`)
はこの約束を確かめる。

## 1. `/other/movie`

### 構成

- `Template`(共通のヘッダー・フッター)の中に、見出し「Movie」と一覧を置く。
- 一覧は、狭い画面で1列(画面幅いっぱい)、広い画面(`lg` 以上)で2列。

### 動画1本の表示(`MovieCard`)

上から順に次を並べる。

| 要素 | 内容 | 未登録時 |
| -- | -- | -- |
| プレーヤー | YouTube の埋め込み。16:9 の枠、`loading="lazy"` | (必須) |
| タイトル | `title`。見出し要素(`h2`) | (必須) |
| 撮影場所 | 項目名「撮影場所」と値 | 欄ごと出さない |
| 撮影日 | 項目名「撮影日」と値(`YYYY-MM-DD` のまま) | 欄ごと出さない |
| メモ | 項目名「メモ」と値。改行はそのまま改行して表示 | 欄ごと出さない |

- 長い文字列は折り返し、横スクロールを出さない。
- カード1枚は `article` 要素とする(テストで1本単位に取り出すため)。

### 並び順

[data-model.md の並び順](../data-model.md#並び順fr-004) に従う。

### 0件のとき

一覧の代わりに「公開している動画はまだありません。」と表示する。

## 2. `/other` の Movie の区分

- 写真の区分の下に、見出し「Movie」と、`/other/movie` への入口(`PillLink`、文言「Movie」)を置く。
- 写真の区分と同じ見た目・同じ並べ方(狭い画面で縦積み・幅いっぱい)。

## 3. 共有部品の変更

- `src/components/YoutubeEmbed.tsx` の iframe(動画・再生リストの両方)に `loading="lazy"` を加える。
  呼び出し側(リプレイ一覧)の書き方は変わらない。
