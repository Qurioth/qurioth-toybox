# Feature Specification: トップページ

**Feature Branch**: `001-home`

**対象画面**: `/` (`src/app/page.tsx`)

**Created**: 2026-08-23

**Status**: Draft

**Input**: User description: "トップページ(src/app/page.tsx)の仕様。Qurioth's Toybox のサイト入口として、サイトの趣旨(TRPG向けツール・シナリオを公開する個人サイトであること)を訪問者に伝え、ヘッダーから各コンテンツへ辿れるようにする画面。既存実装の現行仕様を spec として書き起こすことが目的で、新機能の追加ではない。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - サイトの趣旨を理解する (Priority: P1)

初めて訪れた人として、このサイトが何のサイトなのかを最初の画面で知りたい。TRPGコミュニティの
知人からURLを共有されて来ることが多く、「誰が何を公開している場所なのか」が分からないまま
回遊させたくないため。

**Why this priority**: トップページの存在理由そのもの。ここが伝わらなければ、以降の
ツール・シナリオに辿り着く動機が生まれない。他の要素が無くても単独で価値を持つ。

**Independent Test**: `/` を開き、サイト名と、個人サイトであること・TRPG向けのツールと
シナリオを公開していることが読み取れる文言が表示されることで確認できる。

**Acceptance Scenarios**:

1. **Given** サイトを初めて訪れた訪問者、**When** `/` を開く、**Then** サイト名が画面内で
   最も目立つ見出しとして表示される。
2. **Given** `/` を表示している状態、**When** 本文を読む、**Then** オーナー個人が自由に
   運営しているサイトであること、TRPG向けのツールとシナリオを公開していることが
   日本語で示されている。

---

### User Story 2 - 目的のコンテンツへ移動する (Priority: P2)

訪問者として、トップページから TRPG 向けのツール群、またはそれ以外のコンテンツへ迷わず
移動したい。サイトの入口から各カテゴリの入口までの導線を短く保つため。

**Why this priority**: User Story 1 で趣旨が伝わっても、次の一歩が無ければ回遊できない。
ただし趣旨の提示より後に成立するため P2。

**Independent Test**: `/` のヘッダーから TRPG・OTHER の各一覧へ遷移でき、サイト名から
トップへ戻れることで確認できる。

**Acceptance Scenarios**:

1. **Given** `/` を表示している状態、**When** ヘッダーの TRPG を選ぶ、**Then** TRPG向け
   コンテンツの一覧画面へ遷移する。
2. **Given** `/` を表示している状態、**When** ヘッダーの OTHER を選ぶ、**Then** その他の
   コンテンツの一覧画面へ遷移する。
3. **Given** サイト内の任意の画面、**When** ヘッダーのサイト名またはロゴを選ぶ、**Then**
   トップページへ戻る。
4. **Given** 画面幅が狭い端末で `/` を表示している状態、**When** メニューを開いて項目を
   選ぶ、**Then** 該当画面へ遷移し、メニューは閉じた状態になる。

---

### User Story 3 - 表示テーマを選ぶ (Priority: P3)

訪問者として、明るい配色と暗い配色を自分で切り替えたい。暗い部屋でセッション中に参照する
場面があり、既定のまま固定されると読みづらいため。

**Why this priority**: 無くてもコンテンツには到達できるため優先度は低いが、サイト全体の
読みやすさに関わる。

**Independent Test**: ヘッダーの切替操作でライト/ダークの配色が入れ替わり、別の画面へ
遷移しても選んだ配色が維持されることで確認できる。

**Acceptance Scenarios**:

1. **Given** ライト配色で `/` を表示している状態、**When** ヘッダーのテーマ切替を選ぶ、
   **Then** ダーク配色に切り替わる。
2. **Given** ダーク配色を選んだ状態、**When** 別の画面へ遷移する、または一度離脱して
   後日同じブラウザで再訪問する、**Then** ダーク配色が維持される。

---

### Edge Cases

- 画面幅が狭い端末では、ヘッダーの項目一覧が常時表示されず、開閉できるメニューに
  折りたたまれる。開いている間はテーマ切替とメニューを閉じる操作も同じ場所から行える。
- サイト名が長く、画面幅に収まらない場合は途中で省略し、レイアウトを崩さない。
- 訪問者がテーマを一度も選んでいない場合は、利用環境(OS・ブラウザ)の設定に従う。
- 再訪問した直後は、保存された配色が反映されるまで既定の配色が一瞬表示されることがある
  (現状の挙動)。改善する場合は本specを先に更新する。
- トップページは外部データを参照しないため、通信断でも表示内容は変わらない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: トップページは、サイト名を画面内で最も目立つ見出しとして表示しなければならない。
- **FR-002**: トップページは、オーナー個人が運営するサイトであること、およびTRPG向けの
  ツールとシナリオを公開していることを、日本語の短い文で示さなければならない。
- **FR-003**: 訪問者は、全画面共通のヘッダーから HOME・TRPG・OTHER の3カテゴリへ移動できな
  ければならない。
- **FR-004**: 訪問者は、ヘッダーのサイト名またはロゴから、どの画面からでもトップページへ
  戻れなければならない。
- **FR-005**: 画面幅が狭い環境では、ヘッダーの項目一覧を開閉できるメニューに折りたたみ、
  項目を選んだ時点で自動的に閉じなければならない。
- **FR-006**: 訪問者は、ライト配色とダーク配色を1操作で切り替えられなければならない。
  切替操作は広い画面でも狭い画面でもヘッダーから到達できなければならない。
- **FR-007**: 選ばれた配色は、サイト内の画面を移動しても、ブラウザを閉じて再訪問しても
  維持されなければならない。一度も選ばれていない場合は、利用環境の配色設定に従う。
- **FR-008**: 全画面共通のフッターに、オーナーの外部プロフィール(GitHub・Bluesky)への
  リンクを置き、現在の画面を離れずに別タブで開かなければならない。
- **FR-009**: ブラウザのタブに表示される名称は `Qurioth's Toybox` とし、各画面では
  `<画面名> | Qurioth's Toybox` の形で表示しなければならない。
- **FR-010**: ファビコンは、利用環境の配色設定(明るい/暗い)に応じて視認できるものを
  出し分けなければならない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 初めて訪れた人が、トップページを見てから10秒以内に「誰が何を公開している
  サイトか」を自分の言葉で説明できる。
- **SC-002**: トップページから任意のカテゴリ(TRPG・OTHER)の一覧画面まで、1操作で到達できる。
- **SC-003**: 幅375px の端末で、横スクロールを発生させずにトップページの全内容を読める。
- **SC-004**: 配色の切替が1操作で反映され、画面を移動しても再訪問しても選択が戻らない。

## Assumptions

- 訪問者はオーナー本人、および同じTRPGコミュニティの知人が中心である。会員登録・認証・
  問い合わせフォームなどの機能は持たない。
- サイト共通のヘッダー・フッター・配色切替の仕様は本specで扱い、他画面のspecでは繰り返さない
  ([ADR-0013](../../docs/adr/0013-spec-per-screen.md))。他画面のspecは「共通レイアウトの上に
  何を表示するか」だけを記述する。
- UI文言は日本語を基本とする。多言語対応は行わない
  ([constitution.md](../../.specify/memory/constitution.md) 原則2)。
- 本specは既存実装の現行仕様を書き起こしたものであり、新機能の追加を含まない。トップページの
  文言・導線を変更する場合は、実装より先に本specを更新する(原則3)。
- トップページ自体は外部データやユーザー入力を扱わないため、Key Entities は無い。
