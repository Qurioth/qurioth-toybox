# Contract: 画面(`/trpg/ccfolia-grep`)

上から順に並ぶ操作部品と、その役割。既存部品の位置関係は変えない。

| # | 部品 | ラベル / 初期状態 | 役割 |
|---|---|---|---|
| 1 | ファイル入力(既存) | `CCFOLIA LOG FILE` | HTML / JSON を自動判別して読み込む。読み込むたびに 2・3 の選択肢を作り直し、3 は「すべて」に戻る |
| 2 | 名前プルダウン(既存) | placeholder `キャラクター名` | ログ全体の名前一覧。タブに影響されない |
| 3 | タブプルダウン(新規) | aria-label `タブ`、初期 `すべて` | `すべて` + ログ全体のタブ一覧。単一選択 |
| 4 | 成功度チェックボックス(既存) | `成功度`、初期 クリティカル・成功 | 絞り込み結果にのみ効く(成長チェックには効かない) |
| 5 | 除外チェックボックス(新規) | `成長チェック`、項目 `クトゥルフ神話・信用を除外する`、初期 ON | 成長チェック一覧にのみ効く |
| 6 | 実行ボタン(既存) | `Submit` | 7 と 8 を同時に更新 |
| 7 | 結果テキストボックス(既存) | 見出し `ログ抽出結果` | `**名前**` + コードブロック。コピーボタン付き |
| 8 | 成長チェックテキストボックス(新規) | 見出し `成長チェック一覧` | `**名前**` / `- 成長技能一覧` / `  - \`技能名\``… の箇条書き。内容に合わせた高さ。コピーボタン付き |
| 9 | 根拠行(新規) | 折りたたみ `根拠`(初期は閉) | 8 の各技能について `技能名 — [tab] 名前 本文` を箇条書き。コピー対象外 |

## 振る舞い

- 3 で「すべて」以外を選ぶと、7・8 はそのタブの行だけから作られる。
- 3 は 1 で別ファイルを読み込むと「すべて」に戻る(再マウント)。
- 8・9 は `CC` 系の判定がないログでは見出しと空の囲みだけになる。
- 解釈できないファイルを選ぶと 2・3 の選択肢は空になり、エラー表示は出さない(既存踏襲)。

## テストで使う指名子

- ファイル入力: `getByLabelText("CCFOLIA LOG FILE")`
- 名前プルダウン: `getByRole("combobox", { name: "キャラクター名" })`(`aria-label` を付与)
- タブプルダウン: `getByRole("combobox", { name: "タブ" })`
- 除外チェックボックス: `getByRole("checkbox", { name: "クトゥルフ神話・信用を除外する" })`
