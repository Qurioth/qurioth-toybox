# Feature Specification: キャラクターシートのチャート表示

**Feature Branch**: `004-charaeno-chart`

**対象画面**: `/trpg/charaeno-chart`、`/trpg/charaeno-chart/sample-character`

**Created**: 2026-08-23

**Updated**: 2026-08-23（クトゥルフ神話TRPG 6版のキャラクターシート対応を追加）

**Status**: Draft

**Input**: User description: "Charaeno に保管したクトゥルフ神話TRPGのキャラクターシートを読み込み、能力値をレーダーチャートにしたカードとして表示する画面。7版に加えて6版のシートも同じ入力欄で受け付ける。サンプルキャラクターの一覧ページを含む。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 自分のキャラクターをカードにする (Priority: P1)

クトゥルフ神話TRPGのプレイヤーとして、Charaenoに保管した自分の探索者のURLを渡すだけで、
能力値の傾向がひと目で分かるカードを表示したい。数値の羅列より、卓の場で見せやすいため。

**Why this priority**: この画面の中心的な価値。カードが出せなければ画面の意味がない。

**Independent Test**: キャラクターシートのURLを入力して実行すると、その探索者の名前・
能力値のチャート・主要な数値を含むカードが表示されることで確認できる。

**Acceptance Scenarios**:

1. **Given** Charaenoのキャラクターシートの URL、**When** 入力して実行する、**Then** その探索者の
   カードが表示され、8つの能力値がレーダーチャートとして描かれる。
2. **Given** 7版のキャラクターシートのURL、**When** カードを見る、**Then** HP・MP・SAN・幸運の
   4つの値が併せて表示される。
3. **Given** 名前に括弧書き(ふりがな等)を含む探索者、**When** カードを見る、**Then** 括弧書きを
   除いた名前が表示される。
4. **Given** 対応していない形式のURL、**When** 入力して実行する、**Then** URLの形式が不正である
   ことが日本語で示され、カードは表示されない。

---

### User Story 2 - 6版の探索者も同じ入り口で扱う (Priority: P1)

6版で作った探索者を持つプレイヤーとして、7版のときと同じ入力欄に自分のシートのURLを貼るだけで
カードを出したい。手元には6版の探索者も多く、版を選ぶ操作を増やされるとかえって使いにくいため。

**Why this priority**: 6版のシートしか持たないプレイヤーは、現状この画面をまったく使えない。
利用できる探索者の範囲が広がることは、カードを出せること自体に次ぐ価値がある。

**Independent Test**: 6版のキャラクターシートのURLを、7版と同じ入力欄に入力して実行すると、
版を選ぶ操作なしにその探索者のカードが表示されることで確認できる。

**Acceptance Scenarios**:

1. **Given** 6版のキャラクターシートのURL、**When** 7版と同じ入力欄に入力して実行する、**Then**
   その探索者のカードが表示される。版を選ぶ操作は求められない。
2. **Given** 6版の探索者のカード、**When** レーダーチャートを見る、**Then** 8つの能力値が6版の
   尺度で描かれ、能力値の高低が読み取れる(全ての軸が中心付近に潰れることはない)。
3. **Given** 6版の探索者のカード、**When** 表面の数値を見る、**Then** HP・MP・SAN・ダメージ・
   ボーナスの4つが表示され、幸運は表示されない。
4. **Given** 7版のキャラクターシートのURL、**When** 入力して実行する、**Then** 6版対応を入れる前と
   同じカードが表示される。

---

### User Story 3 - カードの裏面で詳細を見る (Priority: P2)

プレイヤーとして、カードを裏返して技能や設定を確認したい。表面は能力値の傾向、
裏面は細かい設定、と用途を分けたいため。

**Why this priority**: 能力値のカードだけでも価値はあるが、卓での自己紹介には技能や設定も
必要になる。

**Independent Test**: カードを操作すると表面と裏面が入れ替わり、裏面に技能と設定が
表示されることで確認できる。

**Acceptance Scenarios**:

1. **Given** カードが表面を表示している状態、**When** カードを選ぶ、**Then** 裏面に切り替わり、
   技能と設定が表示される。
2. **Given** カードにキーボードの焦点が当たっている状態、**When** 決定または空白キーを押す、
   **Then** カードを選んだときと同じく表裏が切り替わる。
3. **Given** 7版の探索者、**When** 裏面を見る、**Then** バックストーリーの各項目とメモが表示される。
4. **Given** 6版の探索者、**When** 裏面を見る、**Then** 精神的な障害・読んだクトゥルフ神話の
   魔導書・アーティファクト／学んだ呪文・メモが、この順に表示される。
5. **Given** 何も記入されていない設定の項目がある探索者、**When** 裏面を見る、**Then** その項目は
   表示されない。

---

### User Story 4 - サンプルを見て使い方を知る (Priority: P3)

初めて訪れた人として、自分のキャラクターシートを用意しなくても、このツールが何を表示するのかを
確かめたい。

**Why this priority**: 無くても本来の用途は果たせるが、URLを用意する前に結果を見られると
使い始めのハードルが下がる。

**Independent Test**: サンプルキャラクターの一覧を開くと、複数のカードがあらかじめ表示されて
いることで確認できる。

**Acceptance Scenarios**:

1. **Given** キャラクターシートのチャート表示画面、**When** サンプルへの入口を選ぶ、**Then**
   サンプルキャラクターの一覧画面へ遷移する。
2. **Given** サンプルキャラクターの一覧画面、**When** 画面を見る、**Then** あらかじめ用意された
   7版の探索者のカードが並び、本来のカードと同じように表裏を切り替えられる。

---

### Edge Cases

- キャラクターシートを取得できなかった場合(通信の失敗、URLの誤りなど)は、取得できなかった
  ことと、URLの確認・時間をおいた再試行を促す旨を日本語で示す。
- 取得できたが内容がカードの描画に必要な形を満たさない場合は、形式が想定と異なることを
  日本語で示し、カードは表示しない。必要な項目は版によって異なるため、判定した版に応じて
  確認する。
- 対応していない版(6版・7版以外)を指すURLは、形式が不正であるものとして扱う。
- 6版と7版ではカードに出る項目が異なるため、同じ探索者を両方の版で保管している場合、
  読み込んだ版によってカードの内容が一致しないことがある。これは想定どおりの挙動。
- 6版の探索者で、精神的な障害・読んだ魔導書・アーティファクト／学んだ呪文・メモのすべてが
  空の場合、裏面には技能の表だけが残る。
- 名前が長い探索者は、カードの枠に収まるよう文字の大きさを下げる。それでも収まらない場合は
  末尾を省略する。
- 立ち絵が設定されていない探索者は、既定の人物アイコンを表示する。
- 直前に表示していたカードがある状態で取得に失敗した場合は、そのカードを残さず消す。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 利用者は、キャラクターシートのURLを入力して実行できなければならない。
- **FR-002**: 入力は、対応するキャラクター保管サービスの**6版または7版**のシートを指すURLの
  形式に限り受け付けなければならない。形式が異なる場合は、実行前に日本語で理由を示さなければ
  ならない。
- **FR-003**: 取得に成功した場合は、探索者の名前・8つの能力値のレーダーチャート・立ち絵・
  版ごとに定めた主要な数値(FR-014)を含むカードを表示しなければならない。
- **FR-004**: レーダーチャートの軸の並び順は、取得したデータの並びに関わらず常に同じで
  なければならない。
- **FR-005**: 表示する名前は、括弧書き(ふりがな等)を除き、前後の空白を落としたものでなければ
  ならない。
- **FR-006**: 取得に失敗した場合と、取得できた内容が想定の形を満たさない場合とで、利用者に
  示す理由を区別しなければならない。
- **FR-007**: いずれの失敗の場合も、直前に表示していたカードを残してはならない。
- **FR-008**: 利用者は、カードを選ぶ操作、またはキーボードの決定・空白キーで、カードの表裏を
  切り替えられなければならない。
- **FR-009**: カードの裏面には、既定値から変更された技能と、版ごとに定めた設定の項目(FR-015)を
  表示しなければならない。記入の無い項目は表示してはならない。
- **FR-010**: 立ち絵が設定されていない探索者には、既定の人物アイコンを表示しなければならない。
- **FR-011**: 利用者は、キャラクターシートを用意せずにカードの見え方を確認できる、サンプル
  キャラクターの一覧へ遷移できなければならない。
- **FR-012**: 版の判定は、入力されたURLそのものだけから行わなければならない。利用者に版を
  選ばせる操作を追加してはならず、入力欄と実行操作は版によらず1組のままでなければならない。
- **FR-013**: 判定した版に対応するキャラクターシートの内容を取得しなければならない。一方の版の
  URLに対して、もう一方の版の内容を取得してはならない。
- **FR-014**: カード表面に並べる主要な数値は版ごとに定める。どちらの版も4つで、7版は
  HP・MP・SAN・幸運、6版はHP・MP・SAN・ダメージ・ボーナス(「DB」と表示する)とする。
  6版では幸運を表示してはならない。ダメージ・ボーナスは「+0」「+1D4」のように数値とは限らない
  表記で示されるため、取得した表記のまま表示しなければならない。
- **FR-015**: カード裏面の設定の項目と並び順は版ごとに定める。7版はバックストーリーの各項目
  (容姿の描写、イデオロギー／信念、重要な人々、意味のある場所、秘蔵の品、特徴、負傷・傷跡、
  恐怖症・マニア、魔道書・呪文・アーティファクト、遭遇した超自然の存在)に続けてメモ。
  6版は「精神的な障害」「読んだクトゥルフ神話の魔導書」「アーティファクト／学んだ呪文」
  「メモ」の4項目をこの順とする。
- **FR-016**: 6版のカードには、FR-014・FR-015で定めた以外の内容(住所、描写、家族＆友人、
  狂気の症状、負傷、傷跡、遭遇した超自然の存在、所持品、武器、財産など)を表示してはならない。
- **FR-017**: レーダーチャートは、版ごとの能力値の尺度に合わせて描かれなければならない。
  各能力値は、その版・その能力値における上限に対する割合として読み取れなければならない。
  7版の上限は8つとも100、6版の上限はEDUのみ21、それ以外(STR/CON/POW/DEX/APP/SIZ/INT)は18とする。
  上限を超える値は上限として扱い、チャートの枠外へはみ出させてはならない。
- **FR-018**: 取得した内容の検証は、判定した版のカードを描くために必要な項目が揃っているかの
  確認に留めなければならない。一方の版にしか存在しない項目を、もう一方の版に要求しては
  ならない。

### Key Entities *(include if feature involves data)*

- **探索者**: クトゥルフ神話TRPGのキャラクター1人分。版によらず、名前、8つの能力値
  (STR/CON/POW/DEX/APP/SIZ/INT/EDU)、HP・MP・SAN、ダメージ・ボーナス、技能の一覧(既定値から
  変更されたかの区別を含む)、メモ、立ち絵の所在を持つ。
- **版**: 探索者がどのルールで作られたかの区別。6版と7版があり、能力値の尺度(6版はロール値、
  7版はパーセンタイル)と、カードに載せられる項目が異なる。7版のみ幸運とバックストーリーを持ち、
  6版のみ精神的な障害・読んだクトゥルフ神話の魔導書・アーティファクト／学んだ呪文を持つ。
  版は探索者ごとに1つに定まり、入力されたURLから判定される。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: キャラクターシートのURLを貼り付けてから1操作でカードが表示される。この手数は
  6版・7版のどちらでも変わらない。
- **SC-002**: カードが表示できなかったとき、利用者が「URLが違うのか、うまく取得できなかったのか」
  を読み分けられる。
- **SC-003**: 卓の場でカードを見せたとき、相手が能力値の傾向を数値を読まずに把握できる。
  これは6版のカードでも同様に成り立つ。
- **SC-004**: キャラクターシートを持っていない訪問者でも、1操作でカードの実物を見られる。
- **SC-005**: 利用者は、自分の探索者がどの版かを画面上で申告する必要がない。版に関する操作は
  0回である。
- **SC-006**: 6版対応を入れた後も、7版の探索者のカードは対応前と同じ内容・同じ手数で表示される。

## Assumptions

- サイト共通のヘッダー・フッター・配色切替の仕様は [001-home](../001-home/spec.md) で扱い、
  本specでは繰り返さない([ADR-0013](../../docs/adr/0013-spec-per-screen.md))。
- 対象はクトゥルフ神話TRPGの6版と7版のみ。他の版や他システムのキャラクターシートには対応しない。
- キャラクターシートの内容は外部の保管サービスから取得する。当サイトは保存も編集も行わず、
  表示のみを担う。したがって取得元のサービスが停止・仕様変更した場合は表示できなくなる。
  6版・7版それぞれの取得先が独立して変わりうる点も同様。
- 6版のデータには幸運に相当する値やアイデア・知識が含まれていることがあるが、この画面では
  扱わない(FR-014)。表面に並べる数値を版ごとに4つへ固定するのは、ひと目で読める量に保つため。
- 能力値の上限は版ごと・能力値ごとに決まる(FR-017)。チャートの目盛りそのものを能力値ごとに
  変える必要はなく、上限に対する割合として描ければ要件を満たす。
- 取得内容の検証は、カードの描画に必要な項目が揃っているかの確認に留める。全項目の妥当性は
  検証しない(原則1)。
- サンプルキャラクターはリポジトリ内に固定で持つ。画面から追加・編集はできない。今回の
  6版対応では**サンプル一覧に6版の探索者を追加しない**。一覧は7版の探索者のみのままとする。
- 6版対応にあたって、入力欄・実行ボタン・エラー文言・表裏の切り替え方など、版に依存しない
  部分の仕様は変更しない。
