# Quickstart: シナリオ詳細画面の構造化表示を確かめる

実装後、および各シナリオの移行後に行う確認手順。期待する振る舞いの詳細は
[contracts/detail-view.md](contracts/detail-view.md)、本文の前提は
[contracts/structured-markdown.md](contracts/structured-markdown.md) を参照。

## 前提

- `mise` で Node.js、Corepack で pnpm が使えること(CLAUDE.md の開発コマンド参照)
- `pnpm install` 済み

## 1. 自動テスト

```bash
pnpm test
```

期待する結果:

- 分割関数の網羅性テストが通る。全 12 本の本文で、分割結果を連結すると入力と一致する。
- データ適合テストが通る。`structured: true` の全シナリオで、章の順序と能力値の読み取りに
  問題がない。
- 詳細画面の結合テストが通る。表示形式の切り替え、目次、人物カード、判定の強調、読み上げ文
  (テスト用本文で確認)を確かめる。

CI と同じ一連の検査は次のとおり。

```bash
pnpm lint && pnpm format:check && pnpm typecheck && pnpm test && pnpm build
```

## 3. シナリオ 1 本を移行するときの手順

1. 本文を [contracts/structured-markdown.md](contracts/structured-markdown.md) に照らして
   整える。見出し名の揺れ、人物の見出しレベル、立ち絵の位置、規約の項目名、太字の付け忘れ
   (太字の外の `正気度喪失：` など)を直す。文言・数値は変えない。
2. `src/data/scenario/scenario-list.ts` の該当エントリに `structured: true` を付ける。
3. `pnpm test` でデータ適合テストが通ることを確かめる。
4. 2 章の表のうち 2〜8 を、そのシナリオで確かめる。
5. 移行コミットの差分(`git diff`)を見て、本文の変更が見出しや配置の調整だけであることを
   確かめる(SC-008)。

移行はクトゥルフ神話TRPG 7版の 11 本すべてに `structured: true` が付いた時点で完了とする
(spec FR-029 / Assumptions)。
