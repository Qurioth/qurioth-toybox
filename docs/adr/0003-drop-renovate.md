# 0003. Renovate による依存関係自動更新を廃止する

## ステータス

Accepted

## 日付

2026-07-30

## コンテキスト

`qurioth-toybox` では Renovate (`.github/workflows/renovate.yml` + `renovate.json`,
`config:recommended` + `group:all` を extends) を導入し、依存関係更新PRを自動生成していた。

しかし個人開発でレビュー・マージのサイクルが安定しておらず、Renovate が作成するPRを使いこなせて
いなかった(放置・まとめてマージなど運用が定着しなかった)。運用が回っていない自動化を残しておく
ことは、リポジトリの見た目上のノイズや「動いているはずのCIが実は機能していない」という誤解を
招くコストの方が大きいと判断した。

## 決定

- Renovate の設定 (`renovate.json`) と実行ワークフロー (`.github/workflows/renovate.yml`) を削除する。
- 依存関係の更新は当面、必要に応じて手動で行う。
- 将来的に依存更新の自動化が必要になった場合は、運用フロー(レビュー頻度・マージ基準)を先に
  決めた上で再導入を検討する。

## 影響・トレードオフ

- 良い点: 使われていない自動化を除去し、リポジトリの実態とドキュメントの整合性が取れる。
  `RENOVATE_TOKEN` などのシークレット管理も不要になる。
- コスト: 依存関係の更新が手動作業に戻り、放置されるリスクがある。定期的に `yarn outdated`
  (または移行後は `pnpm outdated`) を手動で確認する習慣が必要。
